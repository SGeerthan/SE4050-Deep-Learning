In this project, a dataset named brain_dataset is used, containing two main folders:

Train: Used to train the model to learn tumor features.

Test: Used to evaluate the performance of the trained model.

Each folder contains subfolders representing different tumor types or disease categories.

The process includes:

Data Preparation: Loading, visualizing, and preprocessing MRI images.

Model Training: Using RetinaNet with transfer learning for object detection and classification.

Performance Evaluation: Measuring accuracy, precision, recall, and F1-score.

Visualization: Displaying accuracy, loss, and F1-score plots.

Deployment: Testing the model through Swagger UI for real-time predictions
